# Примеры данных

`ground_truths_all.csv` и `predicts_all.csv` — небольшие синтетические данные:
один положительный пример для калибровки, один положительный и один пустой кадр
для проверки. Это не исходный производственный набор данных.

Воспроизвести входные файлы и иллюстрацию:

```bash
uv run python scripts/create_review_examples.py
```

Запустить пример оценки:

```bash
uv run python scripts/eval.py
```

Скрипт оценки перезапишет `eval_metrics.csv`, `eval_confusion_matrix.csv` и
`eval_best_confidences.json` результатами текущего примера. Сохранённые в истории
Git результаты большого набора не воспроизводятся этими синтетическими данными;
происхождение отсутствующего исходного набора не установлено.
